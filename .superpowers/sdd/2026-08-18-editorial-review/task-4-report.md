## Exact anchors и нормализация

Для `content/course.md` якорь хранит полную дословную исходную строку и declared line. Перед сопоставлением применяется только `NORM-1`:

1. Unicode NFC;
2. CRLF и CR → LF;
3. неразрывный пробел → обычный;
4. серия горизонтальных пробелов → один пробел;
5. края каждой строки обрезаются.

Регистр, `е/ё`, кавычки и пунктуация не нормализуются. Все 285 текстовых якорей после `NORM-1` разрешаются ровно один раз; multi-occurrence selector не потребовался.

Для 20 claim-bearing PNG текстовый поиск по бинарному файлу не имитируется. Детерминированный selector состоит из защищённого SHA-256 PNG, P-ID, `embedded_text`/element selector и дословного видимого текста из inventory. Validator требует единственную P-строку, совпадение source path, exact visible text и текущего бинарного хеша.

## Интегрированные общие span

Каждый общий якорь имеет одну транзакцию `SP-*`; отдельные F-строки только ссылаются на неё. Validator строит обратное отображение `anchor → F set`, требует точного отсортированного списка F-ID в патче и проверяет, что каждый участник ссылается на тот же `SP-*`.

Особенно конфликтные строки получили полную итоговую замену, а не только список независимых действий:

- `SP-C-616`: совместно применяет `F-225 → F-226`, отделяя тенденцию ошибки подтверждения от негарантированного упражнения с факт-листом.
- `SP-C-878`: совместно применяет `F-387 → F-388 → F-389`, оставляя положительную, часто нелинейную связь дохода с благополучием без единого порога и формулы «каждый миллион».
- `SP-C-880`: совместно применяет `F-390 → F-391 → F-392`, объединяя параметры модели World Happiness Report и её наблюдательные ограничения в один абзац.
- `SP-C-882`: совместно применяет `F-393 → F-394 → F-395`, разводя региональное остаточное отклонение модели, актуальные места Коста-Рики и Мексики и неподтверждённые прежние обобщения.

Остальные общие span содержат единую упорядоченную транзакцию: все действия выполняются на одной исходной версии якоря, затем текст сомкнут и пунктуация восстановлена ровно один раз. Это включает все общие P1 span, а не только 28 ранее найденных P2 конфликтов.
