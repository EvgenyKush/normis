# Достаточная версия себя

Курс-антитеза индустрии «лучшей версии себя». Тезис: ценна не версия 2.0, а исходная — **версия Pure**; она уже установлена.

Статический сайт собирается из канонических источников детерминированным генератором. Сборка рабочая: 19 страниц, тихий прогресс чтения, интерактивный тест, шесть писем и экран «сколько это стоит».

## Быстрый старт

```bash
powershell -ExecutionPolicy Bypass -File scripts/build-site.ps1
```

Открыть `index.html`. Для проверки в реальном оформлении нужен любой статический сервер — при открытии через `file://` относительные пути к CSS могут не резолвиться.

Проверка:

```bash
node --test && node scripts/verify-site.mjs
```

79 тестов и верификатор политики сайта. Node 20+, PowerShell. Пакетных зависимостей нет — `package.json` не нужен.

## Структура

```
content/                    ← канон, правится руками
  course.md                 весь курс: 3 части, 6 модулей, «Побеги», тесты, «Неделя», финал
  письма.md                 шесть писем
  support.html              экран «сколько это стоит» с плейсхолдерами
  landing.html              шаблон лендинга с {{ПЛЕЙСХОЛДЕРАМИ}}
scripts/
  build-site.ps1            генератор: канон → HTML
  sync-quiz.mjs             канон → assets/js/quiz.js (--check не пишет, только сверяет)
  verify-site.mjs           политика статики, граф страниц, контракт прогресса
  editorial-baseline.mjs    структурные и текстовые метрики канона
assets/                     CSS-токены, три ванильных JS-модуля, 5 графиков
design/                     дизайн-система SayBriefly: DESIGN.md + токены
docs/editorial/             редакторский отчёт, реестры утверждений, базовые метрики
tests/                      node:test + manual-acceptance.md
site/                       замороженный прототип (референс вёрстки, не собирается)

index.html                  ← сгенерировано, руками не править
course/*.html               ← 10 страниц: index, module-1…6, escapes, week, finale
letters/*.html              ← 7 страниц: index + letter-1…6
support.html                ← экран цены: своя сумма, пропускается одной ссылкой
```

**Сгенерированный HTML никогда не правится руками.** Тест сверяет каждую страницу с выводом генератора: ручная правка роняет сборку.

## Как устроен контент

- **Часть I. Анатомия недостаточности** (модуль 1) — механизмы производства чувства «со мной что-то не так»: маркетинг, соцсети, стыд, эмоциональные качели, магическое мышление и манифестация, прошивки религиозные, поколенческие и родительские, эйджизм, прайм-эра, ИИ-тревога, долженствования, псевдопсихология, прогревы, FOMO.
- **Побеги** — отдельная страница части I: куда уходят от этого чувства. Геймификация и гэмблинг, алкоголь и никотин, копинги и карта замен, спорт-достигаторство, биохакинг, трудоголизм, удобность — у каждого побега названа честная функция и подобрана замена.
- **Часть II. Практика достаточности** (модули 2–5) — инвентаризация фактами, «достаточно» с числом, право на плато, скука и режим, обычность как связь, достаточно хороший родитель.
- **Часть III. Экономика обычной жизни** (модуль 6) — жильё, кредитная кабала, план выхода, деньги и счастье.
- **Неделя обычного человека** — маршрут на 7 дней после прочтения, отдельная страница.
- **Финал** — авторство, амнистия уже наделанному, «когда всё нормально», версия Pure.

Часть I объявлена справочником и читается выборочно; часть II — сердцем курса, по порядку. «Навигатора по боли», обещанного в PROMPT-CODEX, в каноне нет: он существовал во внешнем исходнике и до текущего курса не дошёл.

## Принципы (не нарушать)

1. Продукт сам соблюдает то, чему учит: **никаких** таймеров, «осталось N мест», прогревов, попапов, сбора почты, геймификации чтения. Кнопку можно нажать завтра по той же цене. Это проверяется тестами, а не только совестью.
2. Тон: сухая ирония плюс честные черты на серьёзных темах. Юмор никогда не шутит мимо них.
3. Дизайн строго по `design/DESIGN.md`. Highlighter Yellow — только маркер-выделение, никогда заливка CTA; Bricolage Grotesque 800 — только дисплейные заголовки от 40px; Forest Ink — единственный хроматический авторитет.
4. Медицинские и денежные темы не подаются как диагноз или персональный совет.

## Редакторский слой

Курс прошёл вычитку, литературную редактуру и фактчекинг. Записи:

- `docs/editorial/2026-08-18-editorial-report.md` — существенные правки, реестр решений, источники, статистика;
- `docs/editorial/claims-part-1.md`, `claims-parts-2-3.md`, `claims-merged-sections.md` — инвентари проверяемых утверждений;
- `docs/editorial/baseline.json` — доредакционные метрики, неизменяемая точка отсчёта.

**Стоящее решение:** фактчекинг закрыл 224 из 462 решений статусом «удалено» и сократил курс с 23 540 до ~16 800 слов; часть разделов лишилась аргументации (например, «Быстрая радость и медленное счастье» осталась одними упражнениями). По решению заказчика это состояние сохраняется и не пересматривается. Подробности и цена решения — в `tests/manual-acceptance.md`.

`assets/charts/01-housing-vs-salaries.png` намеренно лежит в репозитории, хотя канон на него не ссылается: решения F-444…F-453 разбирают утверждения, впечатанные в этот график, и привязаны к его SHA-256. Это доказательная база, а не мусор.

## Отличия от PROMPT-CODEX.md

`PROMPT-CODEX.md` — исходное техзадание. Поставленный MVP осознанно отличается:

| ТЗ | Фактически | Почему |
| --- | --- | --- |
| Astro + TypeScript + Content Collections | PowerShell-генератор, ноль зависимостей | Локальный MVP без тулчейна; сборка детерминированная и проверяется тестами |
| Роуты `/course/part-1…3` | Плоские `course/module-1…6.html` | Модули — естественная единица чтения; «Побеги», «Неделя» и финал получили свои страницы |
| `/glossary/` из конфига | Нет | Не реализовано |
| OG-мета и превью-картинки на часть | Нет | Не реализовано |
| Поиск (pagefind) | Нет | Был P2 |
| `focus-visible` жёлтым | Terracotta | Жёлтый на кремовом даёт контраст 1.18:1 — фокус был бы невидим; Terracotta даёт 4.14:1 |

Раздел `/letters/` из ТЗ реализован. Шаринг результата теста картинкой через `<canvas>` — нет.

## Состояние

Сборка, 79 тестов, верификатор и проверки синтаксиса проходят. Дизайн-система проверена программно на 13 страницах в трёх ширинах; эстетическая оценка человеком не выполнена — скриншоты в рабочем окружении недоступны. Подробный отчёт приёмки, ограничения и остаточные риски — в `tests/manual-acceptance.md`.
