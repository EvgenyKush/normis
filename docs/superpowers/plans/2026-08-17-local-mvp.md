# Local MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an autonomous local course website that opens from `index.html`, provides chapter-based reading, an accessible quiz, and resilient local progress without a server or internet connection.

**Architecture:** Static HTML pages share a token-driven CSS system and small dependency-free JavaScript modules. The original Markdown remains the canonical content source; a deterministic PowerShell build script extracts its sections into page templates, while a Node verification script checks links, assets, document structure, and required progressive-enhancement behavior.

**Tech Stack:** HTML5, CSS3, browser JavaScript (ES2018, no modules so `file://` works consistently), PowerShell 7/Windows PowerShell-compatible build script, Node.js built-in test runner and filesystem APIs.

## Global Constraints

- The root `index.html` must open directly from disk; no server, build runtime, package installation, account, analytics, or internet connection is required.
- All internal navigation and asset references use relative paths.
- `content/course.md` is the canonical content source and must not be substantively rewritten during the build.
- The site has eight quiz situations plus one introduction screen and stores no quiz answers outside the current page session.
- Progress storage is optional enhancement: unavailable `localStorage` must never block reading.
- Forest Ink is `#1a3300`, Cream Paper is `#fcfaf5`, and Highlighter Yellow is `#ffe95c`; yellow is not a primary CTA fill.
- The minimum supported viewport is 320 CSS pixels; meaningful content must remain available without JavaScript.
- The current workspace is not a Git repository. Do not initialize Git or add commit steps without separate user authorization.

## File Map

- `content/course.md`: normalized UTF-8 copy of the supplied canonical course.
- `content/landing.html`: preserved semantic content fragments from the supplied landing page used by the build.
- `design/DESIGN.md`, `design/tokens.json`: design reference and machine-readable tokens.
- `assets/css/variables.css`: canonical CSS custom properties.
- `assets/css/theme.css`: resets, typography, colors, focus, and reusable components.
- `assets/css/site.css`: landing-, reader-, navigation-, and quiz-specific layout.
- `assets/js/progress.js`: defensive progress persistence API exposed as `window.CourseProgress`.
- `assets/js/quiz.js`: quiz state machine and accessible rendering.
- `assets/js/site.js`: page bootstrapping and progressive-enhancement hooks.
- `assets/charts/*.png`: five normalized chart assets.
- `scripts/build-site.ps1`: deterministic content-to-pages generator.
- `scripts/verify-site.mjs`: static acceptance checks using Node built-ins.
- `index.html`: generated landing page and quiz host.
- `course/index.html`, `course/module-1.html` … `course/module-6.html`, `course/finale.html`: generated reader pages.
